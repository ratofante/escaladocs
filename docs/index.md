# Escalafy Docs

Chapter-based guides to how the app works, written for the people who maintain it. Each guide opens
with a presentation chapter, then one chapter per page or area where the decisions differ, and closes
with the cross-cutting chapters (operations, measurement).

Every chapter follows the same shape: a plain-words walk-through first, then the mechanisms one at a
time with real snippets from the repo (file and line range), what is different on that page, a request
trace, a file map and the terms.

## Sections

- **Guides**: chapter-based explanations of how the app works.
- **[Skills](./skills/index.md)**: the Claude Code skills used around the app, what each one does and when to type its name.

## Guides

- [Cache and page loads](./guides/cache-and-page-loads/index.md): how pages load on the
